# `mean`

```mojo
fn def mean[dtype: DType](src: Span[Scalar[dtype]]) -> Scalar[dtype]
```

Computes the mean value of the elements in a buffer.

**Parameters:**

- **dtype** (`DType`): The dtype of the input.

**Args:**

- **src** (`Span[Scalar[dtype]]`): The buffer of elements for which the mean is computed.

**Returns:**

`Scalar[dtype]`: The mean value of the elements in the given buffer.

**Raises:**

If the operation fails.
